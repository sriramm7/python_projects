# Python Mini Projects

This repository consists of a group of small, beginner-friendly Python projects that demonstrate core programming concepts.

## Projects Included

1. Fruit Basket Organizer  
   A simple script that helps categorize fruits into different baskets.

2. Multiplication Table  
   Generates multiplication tables for any given number.

3. Square Matrix  
   Performs operations related to square matrices (e.g., printing, manipulating, etc.).

---

## How to Run the Projects

### 1. Clone the Repository

Open a terminal and run:

```bash
git clone https://github.com/sriramm7/python_projects.git
cd projects
python fruit_basket.py for fruit basket organizer
python multiplication_table.py for multiplication table
python square_matrix.py for square matrix
